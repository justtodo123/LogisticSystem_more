## 修改内容

### 1. 创建状态机模块 (`src/backend/services/state_machine.py`)

实现了物流系统中的所有状态流转逻辑：

#### 状态流转规则
1. **F007完成** → 订单状态: `pending` → `delivering`
2. **F021完成** → 货物状态: `pending_pack` → `packed`; 包裹状态: `pending_pack` → `packed`
3. **F005调用** → 货物状态: `packed` → `in_transit`; 包裹状态: `packed` → `in_transit`; 车辆状态: `idle` → `delivering`; 司机状态: `idle` → `busy`
4. **模拟送达（L0→L1）** → 包裹状态: `in_transit` → `delivered`; 货物状态: `in_transit` → `pending_pack`; 批次状态: `pending/l0_l1_done` → `l0_l1_done`; 车辆状态: `delivering` → `idle`; 司机状态: `busy` → `idle`
5. **F021重新打包** → 货物状态: `pending_pack` → `packed`; 新包裹状态: `pending_pack` → `packed`
6. **模拟送达（L1→L2）** → 包裹状态: `in_transit` → `delivered`; 货物状态: `in_transit` → `delivered`; 订单状态: `delivering` → `completed`; 批次状态: `l0_l1_done` → `completed`; 车辆状态: `delivering` → `idle`; 司机状态: `busy` → `idle`

#### 函数说明
- `update_state_after_f005(db, dispatch, package_codes)` - F005调用后的状态更新
- `simulate_delivery_l0_to_l1(db, batch, dispatch)` - 模拟L0→L1送达
- `repack_at_l1(db, order_code, l1_node_code, l2_node_code, schedule_id)` - 在L1重新打包
- `simulate_delivery_l1_to_l2(db, batch, dispatch, order_codes)` - 模拟L1→L2送达
- `check_and_update_order_status(db, order_code)` - 检查并更新订单状态

### 2. 修改节点调度算法 (`src/backend/algorithms/node_dispatch.py`)

#### 修改内容
1. **添加导入** - 导入状态机模块的函数
2. **修改 `_write_dispatches()` 函数** - 在写入调度明细后调用 `update_state_after_f005()` 更新状态
3. **修改 `_run_dispatch_both_levels()` 函数** - 在 `demo_mode=true` 时自动推进状态：
   - L0→L1调度完成
   - 模拟L0→L1送达（包裹 `in_transit` → `delivered`，货物 `in_transit` → `pending_pack`）
   - 在L1重新打包（生成新包裹，状态 `packed`）
   - L1→L2调度完成
   - 模拟L1→L2送达（包裹 `in_transit` → `delivered`，货物 `in_transit` → `delivered`，订单 `delivering` → `completed`）
