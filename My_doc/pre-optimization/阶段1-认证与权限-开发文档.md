## 1. 阶段目标

实现登录认证（JWT Token）和角色权限控制（RBAC），确保：
- 用户可以通过用户名/密码登录获取 Token
- 受保护的接口需要携带 Token 才能访问
- manager 角色无法执行写操作（POST/PUT/DELETE），返回 403

**阶段 1 完成后，系统具备**：
- ✅ 用户认证能力（登录/登出/获取当前用户信息）
- ✅ JWT Token 签发与校验
- ✅ RBAC 权限控制（dispatcher 读写，manager 只读）
- ✅ 统一响应格式 `{ code, message, data, meta }`

## 3. 详细设计

### 3.1 数据库设计

#### 3.1.1 users 表 DDL

```sql
CREATE TABLE users (
    id              BIGINT       NOT NULL AUTO_INCREMENT PRIMARY KEY,
    username        VARCHAR(64)  NOT NULL UNIQUE,
    password_hash   VARCHAR(255) NOT NULL,
    role            VARCHAR(32)  NOT NULL,  -- dispatcher / manager
    display_name    VARCHAR(64)  NULL,
    is_active       BOOLEAN      NOT NULL DEFAULT TRUE,
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

**说明**：
- `id`：内部自增主键，不对外暴露
- `username`：登录用户名，唯一约束
- `password_hash`：bcrypt 哈希后的密码（明文字符串不落库）
- `role`：角色（dispatcher / manager）
- `display_name`：显示名称（如"调度员"、"管理者"）
- `is_active`：账号是否激活（预留字段，MVP 默认 TRUE）
- `created_at` / `updated_at`：时间戳

#### 3.1.2 log_events 表 DDL

```sql
CREATE TABLE log_events (
    id              BIGINT       NOT NULL AUTO_INCREMENT PRIMARY KEY,
    event_name      VARCHAR(64)  NOT NULL,
    user_id         BIGINT       NOT NULL,
    role            VARCHAR(32)  NOT NULL,
    event_data      JSON         NULL,
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

**说明**：
- `event_name`：事件名称（如 `login`、`logout`）
- `user_id`：关联用户 ID（外键 → `users.id`）
- `role`：操作时的用户角色（`dispatcher` / `manager`）
- `event_data`：事件附加数据（JSON 格式，如 IP、User-Agent 等）
- `created_at`：事件发生时间
- 数据保留 30 天（定期清理 `created_at` 超过 30 天的记录）

#### 3.1.3 种子账号

| 用户名 | 密码 | 角色 | display_name |
| --- | --- | --- | --- |
| dispatcher | 123456 | dispatcher | 调度员 |
| manager | 123456 | manager | 物流管理者 |

**密码哈希**：使用 `passlib[bcrypt]` 进行 bcrypt 哈希，示例：
```python
from passlib.context import CryptContext
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
password_hash = pwd_context.hash("123456")
```

### 3.3 JWT 设计

#### 3.3.1 JWT Payload

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| sub | 用户名（username） | "dispatcher" |
| role | 角色（dispatcher / manager） | "dispatcher" |
| exp | 过期时间戳（Unix timestamp） | 1718208000 |

**示例 Payload**：
```json

  "role": "dispatcher",
```

#### 3.3.2 JWT 签名密钥

- **密钥配置**：`JWT_SECRET` 环境变量（存放在 `.env` 中，不提交 Git）
- **算法**：HS256（HMAC + SHA256）

### 3.4 认证与权限依赖设计

#### 3.4.1 get_current_user 依赖

**文件**：`api/dependencies.py`（或 `main.py` 中）

```python
from fastapi import Depends
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
from fastapi.responses import JSONResponse

security = HTTPBearer()

async def get_current_user(
    credentials: HTTPAuthorizationCredentials = Depends(security)
) -> User:
    """
    从 Authorization header 中提取 Token，解码后返回当前用户 ORM 对象。
    如果 Token 无效或过期，返回 JSONResponse（统一响应格式，HTTP 401）。
    """
    token = credentials.credentials
    try:
        payload = decode_token(token)
        username = payload.get("sub")
        if username is None:
            return JSONResponse(
                status_code=401,
                content=error_response(40100, "未登录或 Token 无效"),
            )
        user = get_user_by_username(username)  # 从数据库查询
        if user is None or not user.is_active:
            return JSONResponse(
                status_code=401,
                content=error_response(40100, "未登录或 Token 无效"),
            )
        return user
    except JWTError:
        return JSONResponse(
            status_code=401,
            content=error_response(40100, "未登录或 Token 无效"),
        )
```

#### 3.4.2 require_dispatcher 依赖

**文件**：`api/dependencies.py`

```python
from fastapi import Depends
from fastapi.responses import JSONResponse

def require_dispatcher(current_user: User = Depends(get_current_user)) -> User:
    """
    检查当前用户角色是否为 dispatcher。
    如果角色为 manager，返回 JSONResponse（统一响应格式，HTTP 403）。
    如果 get_current_user 已返回 JSONResponse（401），透传该响应。
    """
    if isinstance(current_user, JSONResponse):
        return current_user  # 透传 401 错误响应
    if current_user.role != "dispatcher":
        return JSONResponse(
            status_code=403,
            content=error_response(40300, "无权限执行此操作（仅调度员可操作）"),
        )
    return current_user
```

#### 3.4.3 使用方式

**公开接口（无需认证）**：
```python
@router.post("/api/auth/login")
def login(credentials: LoginRequest):
    # 无需认证
    pass
```

**需要认证（任何角色）**：
```python
@router.get("/api/auth/me")
def get_me(current_user: User = Depends(get_current_user)):
    # 需要认证
    pass
```

**需要认证 + dispatcher 角色**：
```python
@router.post("/api/orders")
def create_order(
    order: OrderCreateRequest,
    current_user: User = Depends(require_dispatcher)  # 仅 dispatcher 可操作
):
    # 需要 dispatcher 角色
    pass
```

#### 3.5.2 实现方式

**方案选择**：在每个接口中手动构造统一响应（MVP 阶段简单处理，不做全局中间件）。

**封装工具函数**：
```python
# utils/response.py

def success_response(data: any = None, meta: dict = None) -> dict:
    """成功响应"""
    return {
        "code": 0,
        "message": "success",
        "data": data,
        "meta": meta or {"degraded": False, "degraded_reason": None}
    }

def error_response(code: int, message: str, data: any = None) -> dict:
    """错误响应"""
    return {
        "code": code,
        "message": message,
        "data": data,
        "meta": {"degraded": False, "degraded_reason": None}
    }
```

**使用方式**：
```python
from utils.response import success_response, error_response

@router.post("/api/auth/login")
def login(credentials: LoginRequest):
    if not user:
        return error_response(40100, "用户名或密码错误")
    return success_response({
        "access_token": token,
        "token_type": "bearer",
        "expires_in": 86400,
        "role": user.role,
        "display_name": user.display_name
    })
```

| JWT 密钥泄露 | Token 可被伪造 | 密钥仅存后端 .env，不提交 Git；定期更换密钥 |
| Token 无法主动失效 | 登出后 Token 仍有效（直到过期） | MVP 阶段接受此限制；P1 可实现 Token 黑名单 |
| 密码哈希计算慢 | bcrypt 故意设计慢（防暴力破解） | MVP 阶段可接受；如影响性能可调整 bcrypt 成本因子 |

### 9.3 JWT 工具函数（示例）

```python
# services/auth_service.py

from datetime import datetime, timedelta
from jose import JWTError, jwt
from passlib.context import CryptContext
from config import settings

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def create_access_token(username: str, role: str) -> str:
    """签发 JWT Token"""
    expire = datetime.utcnow() + timedelta(seconds=settings.JWT_EXPIRE_SECONDS)
    to_encode = {"sub": username, "role": role, "exp": expire}
    encoded_jwt = jwt.encode(to_encode, settings.JWT_SECRET, algorithm="HS256")
    return encoded_jwt

def decode_token(token: str) -> dict:
    """解码 Token"""
    try:
        payload = jwt.decode(token, settings.JWT_SECRET, algorithms=["HS256"])
        return payload
    except JWTError:
        raise ValueError("Invalid token")

def verify_password(plain_password: str, hashed_password: str) -> bool:
    """验证密码"""
    return pwd_context.verify(plain_password, hashed_password)

def get_password_hash(password: str) -> str:
    """密码哈希"""
    return pwd_context.hash(password)
```
