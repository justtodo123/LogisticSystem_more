```python
# models/node.py
class Node(Base):
    __tablename__ = "nodes"
    
    id = Column(BigInteger, primary_key=True, autoincrement=True)
    node_code = Column(String(64), unique=True, nullable=False, index=True)
    name = Column(String(128), nullable=False)

```

```python
# models/storage_center.py
class StorageCenter(Base):
    __tablename__ = "storage_centers"

    node_id = Column(BigInteger, ForeignKey("nodes.id"), unique=True, nullable=False)
```

```python
    status = Column(String(32), nullable=False, default="pending_pack")
```

### 4.4 错误码定义

**统一错误码格式**（依据架构设计说明书§6.3）：

| code | message | 说明 |
|---|---|---|
| 0 | success | 成功 |
| 40000 | 参数校验失败 | 请求参数错误（HTTP 400） |
| 40100 | 未登录或Token无效 | 未认证（HTTP 401） |
| 40101 | Token已过期 | Token过期（HTTP 401） |
| 40300 | 无操作权限 | 无权限（HTTP 403） |
| 40400 | 资源不存在 | 资源未找到（HTTP 404） |
| 40900 | 资源冲突 | 资源已存在或状态冲突（HTTP 409） |

| 40008 | 司机不存在 | 司机未找到 | GET/PUT/DELETE /api/drivers/{code} |

**业务规则**：
- 仅允许对状态为 `pending_pack`（待打包）的包裹执行 repack

- 新包裹状态为 `pending_pack`（待打包）
- 重新打包的货物必须满足：
  1. 货物状态为 `pending_pack`（未分配）
  2. 货物处于同一个节点

```python
        # 4. 创建新包裹（状态 pending_pack，goods_items 为重新分配的货物）
```
