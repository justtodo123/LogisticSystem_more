## 快速配置流程

### 1) 后端（最小可用）

```bash
cd src/backend
cp .env.example .env.dev
# 编辑 .env.dev，填写 JWT_SECRET（至少 32 位随机字符串）
```

可选：如需 AI 功能，填写 `DEEPSEEK_API_KEY`。

### 2) 前端（最小可用）

```bash
cd src/frontend
cp .env.example .env.local
# 默认全部 VITE_USE_MOCK_*=true，可独立启动前端
# 联调时逐个改为 false 关闭 Mock
```

### 3) Docker 部署

`docker-compose.yml` 使用 `${JWT_SECRET:-change-me-in-prod}` 语法提供默认值。生产部署时通过 `docker-compose.override.yml`（已 gitignore）或环境变量注入真实密钥。
