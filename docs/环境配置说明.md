## 3. 后端环境配置

### 3.1 首次搭建

```bash
cd src/backend

# 创建虚拟环境（Windows）
python -m venv .venv
.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 复制环境变量模板
copy .env.example .env
# 编辑 .env，填入 JWT_SECRET、DEEPSEEK_API_KEY 等
```

### 3.2 环境变量（`.env`）

模板见 `src/backend/.env.example`。说明如下：

| 变量名 | 必填 | 说明 |
| --- | --- | --- |
| `JWT_SECRET` | 是 | JWT 签名密钥，随机长字符串 |
| `JWT_EXPIRE_HOURS` | 否 | Token 过期小时数，默认 24 |
| `DATABASE_URL` | 否 | 默认 `sqlite:///./data/logistics.db` |
| `DEEPSEEK_API_KEY` | 阶段 8 | DeepSeek API 密钥 |
| `DEEPSEEK_API_BASE` | 否 | API 地址，默认官方兼容地址 |
| `CORS_ORIGINS` | 否 | 默认含 `http://localhost:5173` |

### 3.3 启动后端

```bash
cd src/backend
.venv\Scripts\activate
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

- API 文档：http://localhost:8000/docs  
- 健康检查：http://localhost:8000/api/health  

### 3.4 新增 Python 包

见 [开发规范.md §3](./开发规范.md#3-后端依赖管理规范)：

1. `pip install <包名>`  
2. 写入 `src/backend/requirements.txt`  
3. 与代码一起 commit

## 4. 前端环境配置

### 4.1 首次搭建

```bash
cd src/frontend
npm install

copy .env.example .env.local
```

### 4.2 环境变量

| 变量名 | 必填 | 说明 |
| --- | --- | --- |
| `VITE_API_BASE_URL` | 否 | API 根路径；开发期通常用 Vite 代理，可留空 |
| `VITE_USE_MOCK_AUTH` | 否 | `true` 时 Mock 登录；联调前改为 `false` |
| `VITE_USE_MOCK_BASIC_DATA` | 否 | `true` 时 Mock 基础数据；阶段 2+ 联调改为 `false` |
| `VITE_USE_MOCK_SCHEDULE` | 否 | `true` 时 Mock 全局调度；联调前改为 `false` |
| `VITE_USE_MOCK_NODE_DISPATCH` | 否 | `true` 时 Mock 节点间调度；联调前改为 `false` |
| `VITE_USE_MOCK_ROUTES` | 否 | `true` 时 Mock 路线坐标；联调前改为 `false` |
| `VITE_USE_MOCK_SIMULATION` | 否 | `true` 时 Mock 模拟送达；联调前改为 `false` |

开发期推荐在 `vite.config.ts` 中配置代理，将 `/api` 转发到 `http://localhost:8000`。

### 4.3 启动前端

```bash
cd src/frontend
npm run dev
```

访问：http://localhost:5173

### 4.4 新增 npm 包

见 [开发规范.md §4](./开发规范.md#4-前端依赖管理规范)：

```bash
npm install <包名>
git add package.json package-lock.json
```

## 6. 常见问题

| 问题 | 处理 |
| --- | --- |
| `pip install` 失败 | 确认虚拟环境已激活、Python 版本 ≥3.9 |
| `npm install` 慢 | 可配置 npm 镜像（团队统一一种方式） |
| 前端 401 | 检查 Token、后端 JWT_SECRET 是否配置 |
| 数据库文件找不到 | 确认 `src/backend/data/` 目录存在，首次启动会自动创建 |
| 对方拉代码后跑不起来 | 对方是否在 `src/backend` / `src/frontend` 下执行了安装命令 |
