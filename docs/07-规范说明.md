## API 响应格式

### 业务成功

```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "meta": { ... }
}
```

- `data`：业务数据（单对象/列表/分页结构）
- `meta`：可选元数据（`degraded`/`degraded_reason`/分页 `total` 等）

### 分页列表

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [...],
    "total": 150,
    "page": 1,
    "page_size": 20
  }
}
```

### 业务错误

```json
{
  "code": 40001,
  "message": "参数缺失：schedule_code 和 batch_code 至少一个必须提供",
  "data": null
}
```

### AI/外部服务降级

```json
{
  "code": 0,
  "message": "success",
  "data": { "explanation": "AI服务暂时不可用，请稍后重试" },
  "meta": {
    "degraded": true,
    "degraded_reason": "DeepSeek API 超时 (15s)"
  }
}
```

> 降级时 `code` 仍为 `0`（成功），前端根据 `meta.degraded` 判断是否展示降级提示。

### HTTP 层错误

```json
{
  "detail": "Not Found"
}
```

> FastAPI 自动生成的 HTTP 异常（401/403/404/422/500），不含 `code` 字段，前端需分别处理。

## 错误码体系

错误码常量定义在 `src/backend/core/error_codes.py`：

| 范围 | 含义 | 示例 |
|------|------|------|
| `0` | 成功 | - |
| `10001-10999` | 认证/授权错误 | Token 过期、权限不足 |
| `20001-20999` | 资源不存在 | 订单/车辆/节点 404 |
| `30001-30999` | 资源冲突 | 重复编码、状态不允许操作 |
| `40001-40999` | 参数/客户端错误 | 缺少必填字段、格式错误 |
| `50000-50999` | 服务端/数据库错误 | 数据库写入失败 |
| `60001-60999` | AI/外部服务降级 | DeepSeek/地图/Redis 不可用 |

### 使用方式

```python
from core.error_codes import CODE_ORDER_NOT_FOUND, CODE_AI_VALIDATION_FAILED

# 在 API 层返回错误
return error_response(code=CODE_ORDER_NOT_FOUND, message="订单不存在")

# 禁止硬编码错误码数字
```

## 鉴权体系

| 级别 | 依赖函数 | 角色要求 | 使用场景 |
|------|----------|----------|----------|
| 公开 | 无 | 无 | 登录、健康检查、到货确认 |
| JWT | `get_current_user` | 任意已认证用户 | 列表查看、详情查看 |
| 调度员 | `require_dispatcher` | `admin` 或 `dispatcher` | 创建/修改/调度/确认/导出 |

`core/permissions.py` 中还定义了 `require_role(*roles)` 和 `require_permission(*permissions)` 工厂函数，可按需扩展更细粒度权限。

## 前端约定

- **组件名**：PascalCase，多词（`VehicleTaskTable` 而非 `TaskTable`）
- **文件名**：kebab-case（`vehicle-task-table.vue`）
- **Composable**：`use*` 命名（`useGlobalSchedule`），返回 ref/reactive + 方法
- **API 封装**：每个领域一个 `api/<领域>.ts`，通过 `api/request.ts` 的 axios 实例发请求
- **类型**：`types/<领域>.ts`，前后端字段对齐

## 数据库约定

- **主键**：自增 `id` (Integer)
- **业务编码**：`xxx_code` 字段（如 `order_code`/`vehicle_code`），唯一索引
- **时间戳**：`created_at` + `updated_at` (DateTime)，ORM 自动管理
- **删除**：物理删除（不做软删除），`ondelete="CASCADE"` 处理级联
- **迁移**：Alembic `versions/` 目录，每次模型变更生成新迁移
