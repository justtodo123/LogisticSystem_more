## 3. 根因判定

**所有阻断 CVE 均来自基础镜像的 OS 层包**，非应用依赖引入。

- 后端：`python:3.13-slim` 当前标签对应 Debian 13.6，其 `perl-base`、`util-linux`、`ncurses`、`sqlite3`、`systemd` 等包版本含已知漏洞。
- 前端：`nginx:1.27-alpine` 当前标签对应 Alpine 3.21.3，其 `openssl`、`expat`、`libpng`、`libxml2`、`musl` 等包版本含已知漏洞。

**结论：需要升级基础镜像标签，而非修改应用代码或依赖。**
