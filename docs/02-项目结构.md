# 02 — 项目结构

> 最后更新：2026-09-04 | 面向：开发者快速定位代码

## 顶层目录

```
LogisticSystem/
├── src/
│   ├── backend/          # Python 后端（FastAPI）
│   └── frontend/         # Vue 3 前端（Vite + TypeScript）
├── docs/                 # 项目文档（当前有效 + history/历史归档）
├── My_doc/               # 交付材料与项目工作文档（已纳入版本控制的目录）
├── scripts/              # 辅助脚本（初始化数据/用户/审计日志）
├── .github/workflows/    # CI/CD（pytest + 构建 + Docker 镜像推送）
├── docker-compose.yml    # 本地 Docker 一键启动
├── Dockerfile.backend    # 后端镜像（debian:forky-slim + Python 3.13 venv）
├── Dockerfile.frontend   # 前端镜像（node 构建 → nginx 托管）
└── README.md             # 项目入口
```

## 后端结构 (`src/backend/`)

| 目录/文件 | 职责 |
|-----------|------|
| `main.py` | 应用入口：注册 API Router、CORS/幂等/超时/审计中间件、全局异常处理器、`/api/health` 与 `/metrics` |
| `api/` | 路由层，不含业务逻辑；各模块以 `APIRouter` 暴露领域端点 |
| `services/` | 业务逻辑层；同步与异步函数并存，按调用链契约编排算法/数据库/外部服务 |
| `models/` | SQLAlchemy ORM 模型；`base.py` 提供无副作用共享 metadata，`registry.py` 显式注册正式模型 |
| `schemas/` | Pydantic 请求/响应模型，按领域拆分目录 |
| `algorithms/` | 调度算法层：策略基类、工厂、全局/节点调度、路径规划、打包、评分与解释；当前注册 `greedy`/`dummy`，路径规划中的 2-opt 仍为 stub |
| `core/` | 公共基础设施：错误码、统一响应、权限/RBAC、校验器、AI guard 与降级 |
| `middleware/` | FastAPI 中间件：审计、持久化幂等、请求超时等 |
| `config/` | 环境配置、runtime/Alembic 共用 URL 解析、engine/session 与 Redis |
| `utils/` | 通用工具；缓存、schema 管理、SQLite 分类/复制迁移等 |
| `alembic/` | 正式 schema 唯一迁移入口及 revision graph |
| `scripts/` | 初始化脚本、旧 SQLite 安全操作 CLI 与发布 migration gate |
| `tests/` | 单元/集成/API/迁移/协议/故障和性能场景测试；测试数量以带日期证据为准 |
| `load/` | k6 负载脚本、baseline 与结果摘要 |
| `security/` | 镜像扫描策略及安全门禁配置 |

## 前端结构 (`src/frontend/src/`)

| 目录/文件 | 职责 |
|-----------|------|
| `main.ts` | 入口：创建 Vue 应用，注册 Element Plus/Pinia/Router |
| `views/` | 页面组件：`Dashboard.vue`、`Login.vue`、`HealthCheck.vue` + `orders/`、`vehicles/`、`drivers/`、`nodes/`、`packages/`、`goods/`、`exceptions/`、`reports/`、`arrival/`、`settings/` |
| `components/` | 可复用组件：`crud/`(DataTable/Toolbar/Pagination)、`detail/`(EntityDetailDrawer + 各实体 DetailBody)、`schedule/`(RouteMap/RoutePicker/TaskTable/PackagesPanel/SummaryCards 等)、`ai/`(AiAssistantPanel/ExplainResultBody)、`charts/`(SlaGauge/CostTrend/ExceptionPie) |
| `composables/` | 组合式逻辑：`useGlobalSchedule` / `useNodeDispatch` / `useRouteVisualization` / `useSimulationDelivery` / `useExceptionReplan` / `useArrivalConfirm` / `useAiParse` / `usePagedList` / `useDashboardDetail` / `useFocus` |
| `api/` | 后端调用封装 + `request.ts`(axios + 响应拦截 + 401 跳转) |
| `stores/` | Pinia 状态：`auth.ts`(JWT + 用户信息) |
| `router/` | Vue Router 路由配置 + 导航守卫 |
| `types/` | TypeScript 类型定义，按领域拆分 |
| `utils/` | `env.ts`(Mock 开关) / `auth-storage.ts` / `format.ts` / `load-amap.ts` / `geo-projection.ts` / `route-normalize.ts` / `schedule-normalize.ts` / `dispatch-normalize.ts` / `mock*.ts` |

## 寻找代码指南

| 我想... | 去... |
|---------|------|
| 看某个 API 端点怎么实现 | `api/<模块>.py` → 路由函数 |
| 看某个功能的业务逻辑 | `services/<模块>_service.py` |
| 看数据表有哪些字段 | `models/<实体>.py` |
| 看请求/响应需要什么字段 | `schemas/<领域>/*.py` |
| 修改调度算法 | `algorithms/` → `factory.py`；当前注册 `greedy` 与 `dummy`，DeepSeek 不作为调度 engine |
| 查错误码含义 | `core/error_codes.py` |
| 加一个新的鉴权角色 | `core/permissions.py` |
| 加环境变量 | `config/settings.py` + `.env.dev` |
| 看前端某个页面的接口调用 | `api/<领域>.ts` + 对应 `composables/use*.ts` |
