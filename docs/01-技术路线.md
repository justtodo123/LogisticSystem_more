# 01 — 技术路线

> 最后更新：2026-08-11 | 面向：评审/面试/Onboarding

## 技术选型总览

| 层级 | 选型 | 理由 |
|------|------|------|
| **后端框架** | FastAPI (Python 3.13) | 原生 async/await，自动 OpenAPI，Pydantic 深度集成 |
| **ORM** | SQLAlchemy 2.0 + Alembic | 成熟稳定，迁移方案完善，支持 SQLite/PostgreSQL 无缝切换 |
| **数据校验** | Pydantic v2 | 请求/响应自动校验，AI 输出结构化校验层核心 |
| **前端框架** | Vue 3 + TypeScript | Composition API + `<script setup>`，组合式逻辑复用 |
| **UI 库** | Element Plus | 企业后台常用，组件丰富，Vue 3 原生支持 |
| **构建** | Vite | 毫秒级 HMR，Rollup 生产构建 |
| **数据库** | 开发 SQLite / 生产 PostgreSQL | SQLite 零配置快速启动，PostgreSQL 生产部署可通过 DB URL 切换 |
| **缓存** | Redis + 进程内存降级 | Redis 提供持久化缓存，`REDIS_ENABLED=false` 时自动降级为内存 |
| **AI** | DeepSeek API | 自然语言→调度参数解析 + 方案解释/审查/异常分析；Pydantic 校验层把关 |
| **地图** | 高德 JS API v2.0 | 真实道路路径渲染 + Driving 路线规划；无 Key 自动降级 Canvas 折线 |

## 分层架构

```
┌──────────────────────────────────────┐
│          前端 (Vue 3 + Vite)          │
│   views/ → components/ → composables │
│       ↕ axios + Mock 开关             │
├──────────────────────────────────────┤
│        API 层 (FastAPI Router)        │
│   路由 → 鉴权(dependencies) → 参数校验 │
│       ↕ service 调用                  │
├──────────────────────────────────────┤
│         Service 层 (业务逻辑)          │
│  编排：schedule / dispatch / replan   │
│   AI：deepseek + ai_suggestion        │
│  外部：map / export / report / erp    │
│       ↕ 算法调用 / ORM                 │
├──────────────────┬───────────────────┤
│  Algorithm 层    │   Model 层 (ORM)   │
│  策略模式工厂     │  SQLAlchemy 模型   │
│  GlobalSchedule  │  Alembic 迁移      │
│  NodeDispatch    │                   │
│  RoutePlanning   │                   │
│  Scoring         │                   │
├──────────────────┴───────────────────┤
│         基础设施 (core/middleware)     │
│  权限(RBAC) / 审计 / 幂等 / 超时降级   │
│  Redis 缓存 / 错误码 / AI 守卫 / 校验  │
└──────────────────────────────────────┘
```

## 核心数据流（调度引擎）

```
unassigned 订单
    │
    ▼
[F007] 全局调度 draft（GlobalSchedule）
    │  参数：algorithm={greedy} + weights
    │  算法：GreedyGlobalScheduleStrategy
    │         ├─ L0：订单→仓储中心（就近）
    │         ├─ L1：仓储→分拣中心（容量+时窗）
    │         └─ L2：分拣中心→末端网点
    ▼
[F021] confirm → active
    │  打包（packaging）：同一路线订单→包裹
    │  生成 NodeDispatch ×N（按层级+车辆）
    ▼
[F005] 节点调度（NodeDispatch）
    │  车辆分配 → 多目标评分 → Top-K 候选
    ▼
[F006] 路径规划（RoutePlanning；2-opt 现为 stub）
    │  距离：真实路网 → 直线×系数 → Haversine 三档
    ▼
[F008] 模拟送达 → 异常检测 → 重规划（3策略）
```

## 技术边界与降级策略

| 外部依赖 | 正常 | 降级 | 触发条件 |
|----------|------|------|----------|
| DeepSeek API | AI 解析/解释/审查/分析 | 本地规则 + Pydantic 默认参数 | `DEEPSEEK_API_KEY=""` 或超时 |
| 高德地图 API | 真实道路路径渲染 + 距离/ETA | Canvas/SVG 折线 + Haversine 直线距离 | `MAP_API_KEY=""` |
| Redis | 持久化缓存 + 幂等存储 | 进程内存 dict 缓存 | `REDIS_ENABLED=false` |
| SMTP/企业微信 | 邮件/IM 通知 | Console 打印 | `NOTIFICATION_CHANNELS=console` |
| ERP Webhook | API Key 鉴权 | JWT 回退鉴权 | `ERP_API_KEY=""` |
