## Mock 自测（答辩主路径）

1. 六项既有 Mock + `VITE_USE_MOCK_EXCEPTIONS=true`
2. Dashboard 生成全局调度
3. 异常页录入 **node** 异常，选择 `related_schedule_code`
4. 触发 **redispatch** → 成功提示新 `schedule_code`
5. 自动跳转 Dashboard，下拉见 **v2 · 重规划**；v1 仍可切换

**reroute 次路径**：需先在 Dashboard 完成节点间调度（生成 route），再在异常页选 road + 路线下拉 → replan → 提示 `new_route_code`（不跳转新 schedule）。
